## Install Guide
1. Copy [this link](https://github.com/Aze543/Origins---Rose-Red-Theme-for-Revenge/raw/refs/heads/main/Origins%20-%20Rose%20Red) pointed to the JSON file
1. Copy [this link](https://github.com/Aze543/Origins---Rose-Red-Theme-for-Revenge/raw/refs/heads/main/Origins%20-%20Rose%20Red) pointed to the JSON file
2. Make your way down to the `Themes` section, under `Bunny` or `Revenge` in Discord's `Settings`
3. Hit the `+` button, and then install the them by `Importing the source url (the url you copied), then hit install`
4. Use the theme you download, then restart the Revenge App.
